# 替群組成員標記已購票

## Why

目前「已購票」只能由登入者標記自己，無法反映一人替多位群友購票的實際情境，導致群組內看到的持票名單不完整。需要讓購票者能替同群組成員建立可追蹤且不互相覆蓋的購票標記。

## What Changes

- 保留既有「標記自己已購票」操作，並在 GameModal 提供替群組成員標記已購票的入口。
- 允許購票者一次選擇一位或多位同群組成員，個別新增或移除自己建立的代購標記。
- 將本人標記與群友代購標記彙整為一致的「已購票」狀態，供賽事詳情、賽事卡片、篩選器與「我的標記」使用。
- 限制代購寫入範圍：購票者只能管理自己建立的代購紀錄，
  新增紀錄時雙方必須屬於同一群組；被標記者可清除套用在自己身上的紀錄。
- 以 UID 去重群組成員，並避免在「好友狀態」中把登入者本人重複列為好友。

## Capabilities

### New Capabilities

- 無。

### Modified Capabilities

- `group-tags`: 新增替同群組成員標記已購票、彙整本人與代購狀態，
  以及限制代購紀錄寫入權限的需求。

## Impact

- 前端：`GameModal.vue`、`GameCard.vue`、`MyMarksModal.vue`、`useMarks.js`、
  `useFilters.js` 與群組標記共用工具。
- 資料層：Firebase Realtime Database 的使用者賽事標記結構與寫入函式。
- 安全性：`database.rules.json` 需新增僅限代購者本人且驗證共同群組的細粒度規則。
- 相容性：保留既有 `ticketPurchased` 布林值，不需要搬移現有資料或新增套件。
