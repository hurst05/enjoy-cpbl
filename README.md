# Enjoy CPBL (中華職棒賽程與售票日曆)

Enjoy CPBL 是一個專為中華職棒球迷打造的互動式 Web 應用程式。整合了賽程表、售票資訊、啦啦隊班表以及好友群組功能，讓球迷能更輕鬆地規劃進場看球的行程。

## 🌐 系統演示 (Live Demo)

<https://enjoy-cpbl.web.app/>

## 🌟 核心功能 (Features)

- **📅 互動式賽程日曆**
  - 提供桌面板(網格)與手機板(列表)雙介面。
  - 清楚標示每日對戰組合、時間、地點與主題日資訊。
  - 直接在日曆上顯示各球團的 **開賣/售票時間** 與階段（自動合併去重）。
- **👯‍♀️ 啦啦隊班表查詢與過濾**
  - 賽事卡片上會顯示預定出席的啦啦隊成員。
  - 提供專屬過濾器，可快速篩選出特定女孩有上班的場次。
- **📌 個人賽事標記與行事曆整合**
  - 登入帳號後，可將有興趣的賽事標記下來。
  - 在「我的標記」清單中，支援進階兩階段篩選與同日賽事群友意向彙整。
  - 支援將所選賽程一鍵匯出至 Google Calendar。
- **👥 好友群組共享**
  - 建立專屬群組並透過代碼邀請好友加入。
  - 日曆與標記清單會同步顯示群組內成員的看球意願，方便球迷揪團。
- **⚙️ 後台管理系統**
  - 管理員可直接透過網頁介面更新主題日、修改售票規則、更新賽程與啦啦隊班表。

## 🛠️ 技術棧 (Tech Stack)

- **前端框架**: Vue 3 (Composition API)
- **建置工具**: Vite
- **後端/資料庫**: Firebase (Authentication, Firestore, Database)
- **樣式**: SCSS (無 Tailwind)
- **爬蟲工具**: Node.js + Puppeteer (用於同步腳本)

## 🚀 本地開發指南 (Development)

1. **安裝依賴**:

   ```bash
   npm install
   ```

2. **啟動開發伺服器**:

   ```bash
   npm run dev
   ```

3. **資料爬取與同步腳本** (選項):

   ```bash
   npm run sync-schedules    # 同步中職賽程
   npm run sync-cheerleaders # 同步啦啦隊班表
   ```

4. **建置發布版本**:

   ```bash
   npm run build
   ```
